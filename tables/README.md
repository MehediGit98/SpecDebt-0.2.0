# Table data

This directory contains standalone CSV representations of the two tables used by the MethodsX article. The manuscript itself is intentionally **not** included in this code/results/figures supplement.

- `table_1_full_grid_decision_summaries.csv`: full-grid decision summary for the daylight and synthetic-scoring demonstrations.
- `table_2_method_specifications.csv`: method/specification metadata table.

The complete underlying numerical grids remain in `results/`, including the per-specification CSV files and declaration curves.
